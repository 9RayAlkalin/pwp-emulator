# Canvas 场景流程

选中谱面并点击 `加载` 时只准备音频、谱面和曲绘资源，Canvas stage 保持隐藏。点击 `开始` 后才绘制选曲 StartInfos 的 loading 场景，从首帧绘制完成起保持 1.5 秒，按导出的 `StartInfoFadeOut` 曲线滑出，再播放 gamescene 整体谱面展开及 HUD 开场。展开期间，真实谱面固定在即将开始的位置，判定线、自定义贴图、文字和音符随同一曲线从中央向两侧展开；不再使用一条临时判定线替代，也不再延迟到中途才显示真实谱面。入场期间音乐和谱面时钟停止，不判定、不计分、不播放打击反馈，完整 1.5 秒入场结束后才一起启动。

设置中的 `跳过加载动画` 只跳过 loading 界面及其离场，仍保留完整 gamescene 入场。暂停和结算的重试也遵循相同门槛。入场预览按曲目、起播位置、画布尺寸和设置缓存，调整设置/窗口时重建，减少重复绘制；HUD 与 cover 保留各自已有的入场和图层顺序。此整体展开是模拟器按用户要求的行为，非原游戏逐帧等价结论。

暂停、继续、重试、返回和结算按钮都由原始 Unity 场景的 Canvas 几何命中。继续使用原始 3 秒倒计时；结算使用原始 `LevelOvarAnimation` 入场曲线。结算的同步和 collection 是本地 fake 状态，达到 A 档分数后显示本地 collection，不发起网络请求。

HTML 设置中的“结算收藏品”可选择原场景的四种图标：Data、头像、曲绘、收藏品档案。Data 数量和物品名称可自定义；显示方式可设为自动（A 及以上）、始终显示或不显示。默认仍为自动显示 1.00 MB；开始显示的 2 秒门槛和原场景动画保留，设置会保存并同时用于播放和导出。

结算音乐使用原版四套 `LevelOver0–3`，分别对应 EZ、HD、IN、AT；其余难度按原生逻辑回退到 IN。在结算场景出现时开始循环，离开结算停止，音量跟随音乐音量设置。

“导出视频”增加独立的“包含 Loading”和“包含 Result”选项。起止时间仍表示谱面区间；从 0 秒开始会保留 Gameplay 进场，勾选 Loading 时额外加入 1.5 秒展示和原始离场动画。勾选 Result 时追加 0.2 秒结束余量、3.5 秒 Gameplay 退场及结算，结算默认保留 7 秒，可设为 3.5–60 秒，包含完整入场、Fake Sync 和自定义收藏品。勾选“含音乐”时，谱面音乐按开场长度延后，结算段加入对应 BGM。导出按固定帧时间求值，完成或取消后恢复原画面与播放位置，不写入最佳成绩。

帧渲染与编码已拆分，可选择 FFmpeg.wasm 或 WebCodecs。编码、位深、容器、硬件偏好和多线程设置见 [视频导出](video-export.md)。

Fake sync 在结算后 2 秒展开同步条，播放原始 `SyncShow` 和三枚斜块的 `Sync` 闪动。原生 0.5 秒准备等待后，本地模拟响应再保持一个闪动周期，随后播放 `SyncSuccess`：闪白、显示“已同步”、收拢并消失。每次结算重新计时，动画不依赖网络或残留定时器。

曲绘裁切使用原始平行四边形路径；图片覆盖遮罩时不重复填充白色遮罩底色，避免抗锯齿边缘露出白线。

暂停按钮的阴影按各自图标的透明轮廓生成和挖空，保留柔和光晕；阴影缓存按 Sprite 区分，避免产生矩形方框。

曲终先播放 gameplay HUD 退场，保留背景并等待原生 3.5 秒结束门槛，再进入结算。半透明面板的阴影使用原始 TrueShadow 参数及四角采样模糊。原机资源加载时间和浏览器字体栅格化仍可能产生差异；当前 99.9% 整图 RGB 验收尚未通过。

玩家名称、Player ID、头像、RKS、Challenge Mode 数值与颜色、名称显示开关在 HTML 设置中编辑；Result 右上角的玩家栏和所有场景画面仍由 Canvas 绘制。历史最佳分数保存在浏览器 `localStorage` 的 `pwp.records`，记录键使用谱面资源路径。

头像列表自动读取 `assets/avatars/index.json`，开发启动和构建会从头像文件生成索引。Loading 从 `assets/tips.txt` 每个非空行中随机选一条提示；更新文件后刷新页面即可生效。
